# 🧹 表格清洗台 (Table Cleaner)

本地隐私优先的 CSV / TSV 表格清理工具 —— **纯前端 · 单文件 · 无依赖 · 数据不上传任何服务器**。

![零上传](https://img.shields.io/badge/privacy-local--only-brightgreen)

## 它解决什么
把脏乱的表格（从系统/微信/邮件导出的 CSV、TSV、txt）拖进浏览器，几下点选就导出干净表格：

- ✅ **去首尾空格**（“ 张三 ” 与 “张三” 对不上导致匹配失败的头痛）
- ✅ **删空行 / 按整行去重**
- ✅ **按指定列去重（保留首次）**
- ✅ **按列筛选关键词**（筛出/筛掉含某词的行）
- ✅ **导出 CSV / TSV**
- ✅ **一键恢复原始数据**
- ✅ **自动处理 GBK / GB18030 编码**（国内导出的中文表常踩乱码，已内置兜底）

## 为什么值得用
- 🔒 **全程本机浏览器运行，数据绝不上传** —— 敏感名单/订单敢交给它。
- 🚫 **无需安装**，打开网页即用；不开会员不收费。
- 一个文件到底，部署极简。

## 快速使用
浏览器打开 `index.html`，或本地启动：

```bash
# 任选其一
python3 -m http.server 8137
npx serve .
```

然后把 `.csv / .tsv / .txt` 拖进页面即可。

## 部署（静态托管，任选）
静态页，任何静态托管都行：GitHub Pages / Netlify / Cloudflare Pages / Vercel。
参考 `docs/DEPLOY.md`。

## 技术说明
- 纯浏览器端 JS：自研 CSV/TSV 解析器（支持引号包裹字段、字段内逗号/换行），无第三方库、无构建步骤。
- 测试：`node` 单测覆盖解析/分界探测/往返（PASS）。
